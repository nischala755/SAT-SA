SAT-SA

Supervisory Analytics Tool for SOC Assessment

Smart India Hackathon · NCIIPC problem statement · Synthetic offline prototype

Periodic SOC evidence → explainable review indicators → source records → human decision

Find which Critical Sector Entities and samples deserve examination, with a reason an examiner can check.

Not a SOC, SIEM, real-time monitoring platform, or automated compliance decision maker.

Architecture and evidence boundary

Web workspaceNext.js and TypeScript present assessment context, filters, source drill-down, report and human review.
API and workflowFastAPI validates imports, owns jobs and identity, serves paginated records and records audit events.
AnalyticsVersioned Python rules evaluate eight supervisory families, negative space, matched peers and review priority.
Local storageImmutable Parquet evidence and DuckDB metadata preserve provenance, run configuration and decisions.

Docker Compose runs locally without runtime Internet access. Ground-truth labels live outside analytical inputs and normal evidence APIs.

Negative space is an explicit review question

Declared monitoring expectations establish which critical assets should be represented in submitted evidence.

The result states expected, observed and missing records, plus confidence and limitations.

No alert activity is a proxy. It does not prove a monitoring control failed.

Actual local demo: four assets have no submitted alert activity; examiner can inspect the source references.

From indicator to source evidence

The examiner sees the observation, predicate, calculation, completeness and supervisory hypothesis.

References resolve to entity-scoped normalized records with source provenance.

A human records an outcome and note. The audit trail preserves that action without rewriting the analytics.

Actual demo capture. Indicators are prompts for review, not findings.

Submission evidence and next validation gate

The deterministic demo covers 8 CSEs, 2 sectors, 6,816 alerts, 852 cases and 192 assets.

Tests cover immutable versions, relationship integrity, analytical rules, API workflow, browser flow and disconnected runtime.

Expert manual-review comparison remains unmeasured. Million-record performance and production accreditation are open gates.

Selected-run report can be printed or downloaded as JSON with run hash and evidence references.
