# SAT-SA demo script (under two minutes)

The companion video is a silent capture of the running local Compose application with a synthetic dataset. It does not use mock indicators or narration. Presenters can use this script as live commentary.

| Segment | Narration |
| --- | --- |
| Overview | “These totals come from an immutable synthetic submission. The tool highlights review indicators, not non-compliance findings.” |
| Entity and evidence | “I select a CSE, open a fast-closure indicator, inspect its rule and completeness, and resolve a source reference to a submitted record.” |
| Negative space | “The asset inventory declares monitoring expectations. Four critical assets have no alert activity in the submitted period. This is a question for the examiner, not proof that monitoring failed.” |
| Period comparison | “Two stored annual submissions are compared by 30-day rates. Cohort changes or missing data are marked unavailable. A changed count alone cannot establish a control outcome.” |
| Report | “The selected run produces a printable report with source references, run hash, limitations and recorded human decisions.” |
| Validation and audit | “Synthetic labels are kept outside analytics. Validation reports that limited benchmark separately from human-reviewed outcomes. Audit entries preserve examiner actions.” |

For a live demonstration, select the `demo` 2025 run and the `demo-2024` run generated by the README instructions. Never describe synthetic benchmark metrics as NCIIPC expert performance.
